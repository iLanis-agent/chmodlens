What a umask gives new files

Follows GNU coreutils chmod on Linux. Its test fixtures (652 cases) come from running chmod 8.32 on a real file and directory. Octal digits add read 4, write 2, execute 1 per class; a leading digit adds setuid 4, setgid 2, sticky 1. In ls output a special bit shows as s or t over an execute bit, and as S or T when execute is off. X sets execute only on directories or when some execute bit is already set. On directories GNU chmod keeps setuid and setgid unless the expression names s. New files start at 666 and directories at 777, minus the umask. The first mode you edit is the starting point for the expression; other systems (BSD, macOS) differ in details. Runs in your browser, nothing stored.
